# Telegram Manager

Локальная веб-панель для работы с Telegram-группами. Доступны единый локальный запуск и подключение Telegram-аккаунта с поддержкой кода и двухэтапной проверки.

## Требования

- Python 3.11 или новее;
- Node.js 20 или новее;
- npm.

## Установка

Команды ниже выполняются из корня проекта.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
npm --prefix frontend ci
Copy-Item .env.example .env
```

Файл `.env` необязателен: приложение по умолчанию слушает только `127.0.0.1:8000`.

## Обычный запуск

Соберите интерфейс и запустите приложение:

```powershell
npm --prefix frontend run build
python launcher.py
```

Launcher дождётся ответа backend и откроет `http://127.0.0.1:8000`. Для запуска без браузера используйте `python launcher.py --no-browser`. Остановка — `Ctrl+C`.

## Подключение Telegram

1. Получите `api_id` и `api_hash` в разделе API development tools на `my.telegram.org`.
2. Откройте раздел «Аккаунт» и укажите API-реквизиты и телефон в международном формате.
3. Введите код из Telegram. Если включена двухэтапная проверка, панель отдельно запросит облачный пароль.

После входа Telethon-сессия хранится в `data/sessions`, а API-реквизиты — в локальном `data/auth.json`. Эти файлы исключены из git и не возвращаются через API. Не переносите каталог `data` на общий или недоверенный компьютер.

Кнопка «Отключить» завершает клиент только до следующего запуска приложения. Она не отзывает Telegram-сессию и не удаляет локальные файлы.

## Выбор группы

После подключения аккаунта откройте раздел «Группы». Панель загружает доступные диалоги, оставляет группы и супергруппы, поддерживает поиск и постраничный просмотр. Публичную группу можно открыть по `@username` или ссылке `https://t.me/username`; приложение не вступает в неё автоматически.

Перед выбором источника выполняется отдельная проверка списка участников. Если Telegram скрывает список или требует права администратора, группа получает состояние «Нет доступа» и не выбирается. Успешная проверка означает только доступ к выдаваемой Telegram выборке и не гарантирует полный список участников.

## Сбор участников

После выбора источника откройте раздел «Задачи» и нажмите «Начать сбор». Приложение выполняет работу в фоне, сохраняет участников пакетами и показывает прогресс без блокировки интерфейса. Одновременно может выполняться только один сбор; активную задачу можно отменить.

При ограничении Telegram задача переходит в состояние ожидания на предписанное время и затем продолжает работу. Уже сохранённые пакеты не теряются, а повторный сбор обновляет данные пользователей без создания дублей. История и итоговые счётчики сохраняются между запусками приложения; незавершённая при аварийной остановке задача помечается ошибкой `interrupted`.

## Просмотр и экспорт результатов

В истории задач нажмите «Результат», чтобы открыть участников конкретного сбора. Таблица использует серверные поиск и пагинацию, поэтому не загружает весь результат в память браузера. Можно переключаться между задачами, включая пустые, отменённые и частично завершённые сборы.

Кнопка «Скачать CSV» экспортирует только выбранную задачу. Файл содержит UTF-8 BOM для корректного открытия Unicode в Excel; запятые, кавычки и переносы строк экранируются по правилам CSV, а потенциальные формулы обезвреживаются.

## Режим разработки

Backend и Vite запускаются в разных терминалах:

```powershell
python -m uvicorn backend.app.main:app --reload --host 127.0.0.1 --port 8000
```

```powershell
npm --prefix frontend run dev
```

Панель будет доступна по адресу `http://127.0.0.1:5173`; запросы `/api` Vite направляет на FastAPI.

## Проверка

```powershell
python -m pytest
npm --prefix frontend run build
```

Проверить backend вручную можно командой:

```powershell
Invoke-RestMethod http://127.0.0.1:8000/api/health
```

Основные маршруты задач: `POST /api/tasks/parse`, `GET /api/tasks`, `GET /api/tasks/{id}`, `POST /api/tasks/{id}/cancel`. Результаты доступны через `GET /api/tasks/{id}/members`, экспорт — через `GET /api/tasks/{id}/export.csv`. Обновления прогресса публикуются через `ws://127.0.0.1:8000/ws/tasks`.

## Настройки

| Переменная | Значение по умолчанию | Назначение |
|---|---|---|
| `TELEGRAM_MANAGER_HOST` | `127.0.0.1` | Адрес backend |
| `TELEGRAM_MANAGER_PORT` | `8000` | Порт backend |
| `TELEGRAM_MANAGER_CORS_ORIGINS` | адреса Vite на порту `5173` | Разрешённые источники frontend |
| `TELEGRAM_MANAGER_DATA_DIR` | `data` в корне проекта | Каталог локальных данных |
| `TELEGRAM_MANAGER_DEBUG` | `false` | Включает `/api/docs` и OpenAPI |
| `TELEGRAM_MANAGER_LOG_LEVEL` | `INFO` | Уровень журналирования |

Секреты, Telegram-сессии и каталог `data` не должны попадать в систему контроля версий. Приложение рассчитано на локальный запуск; не меняйте адрес на публичный без отдельной настройки безопасности.
